# CalcHub - Universal Calculators Website

## Overview

CalcHub is a comprehensive, feature-rich calculators website built with **Tailwind CSS**, **HTML**, and **JavaScript**. It provides 50+ free calculators organized into 6 main categories.

## Features

### 📊 Percentage Calculators
- Calculate Percentage
- Percentage Increase/Decrease
- Discount Calculator
- Markup Calculator

### 💰 Financial Calculators
- EMI Calculator
- Simple Interest Calculator
- Compound Interest Calculator
- Investment Calculator

### 🔄 Conversion Calculators
- Length Converter (meter, km, cm, mm, mile, yard, foot, inch)
- Weight Converter (kg, g, mg, lb, oz, ton)
- Temperature Converter (Celsius, Fahrenheit, Kelvin)

### ❤️ Health & Fitness Calculators
- BMI Calculator
- Calorie Burn Calculator
- Age Calculator
- BMR (Basal Metabolic Rate) Calculator

### 🔢 Math Calculators
- GCD & LCM Calculator
- Area Calculator (circle, square, rectangle, triangle)
- Volume Calculator (sphere, cube, cylinder, cone)
- Power Calculator

### 🎓 Education Calculators
- GPA Calculator
- Student Percentage Calculator
- CGPA Calculator

## Technology Stack

- **HTML5** - Structure and markup
- **Tailwind CSS** - Styling and responsive design
- **Vanilla JavaScript** - All calculations and interactions
- **No External Dependencies** - Lightweight and fast

## File Structure

```
├── index.html          # Main HTML file with structure
├── styles.css          # Custom CSS styles and animations
├── script.js           # All calculator logic
└── README.md           # Documentation
```

## How to Use

1. Open `index.html` in your web browser
2. Navigate to a calculator category
3. Enter the required values
4. Click the calculate button
5. View the results instantly
